# Arcade Base

The shared library and tooling for [Softbody Arcade](https://github.com/softbody-arcade) minigames for BeamNG.drive multiplayer (BeamMP).

Every Softbody Arcade game runs on it: lobby and ready-up, spectating, the settings app, cars, the leaderboard, the HUD, round conditions and the repo tooling the game repos share. [Cops and Robbers](https://github.com/softbody-arcade/cops-and-robbers) is the first game to move onto it.

Work is tracked on the [Softbody Arcade board](https://github.com/orgs/softbody-arcade/projects/1).
