# Arcade Base

The shared library and tooling for [Softbody Arcade](https://github.com/softbody-arcade) minigames for BeamNG.drive multiplayer (BeamMP).

It will hold what every Softbody Arcade game needs: lobby and ready-up, spectating, the settings app, cars, the leaderboard, the HUD and round conditions, plus the repo tooling the game repos share. No game runs on it yet; [Cops and Robbers](https://github.com/softbody-arcade/cops-and-robbers) is the first to move onto it.

Work is tracked on the [Softbody Arcade board](https://github.com/orgs/softbody-arcade/projects/1).
